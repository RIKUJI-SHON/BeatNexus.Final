# 🔧 パスワードリセット問題解決手順

## 🚨 現在の状況
- メールが送信されているが、リンクをクリックしても認証画面が表示されない
- Supabaseの認証URL変数 `{{ .ConfirmationURL }}` が正しく動作していない可能性

## 🔍 問題の原因候補

### 1. Supabaseのサイト設定問題
**確認項目:**
- Site URL: `http://localhost:3000` に設定されているか
- Redirect URLs: `http://localhost:3000/reset-password` が許可されているか

**設定場所:**
https://supabase.com/dashboard/project/wdttluticnlqzmqmfvgt/auth/url-configuration

### 2. メールテンプレートの問題
**現在の設定:** `{{ .ConfirmationURL }}`
**推奨設定:** `{{ .SiteURL }}/reset-password?token_hash={{ .TokenHash }}&type=recovery`

## 🛠️ 解決手順

### Step 1: Supabaseサイト設定確認
1. [URL Configuration](https://supabase.com/dashboard/project/wdttluticnlqzmqmfvgt/auth/url-configuration)を開く
2. **Site URL:** `http://localhost:3000` を設定
3. **Redirect URLs:**に以下を追加：
   ```
   http://localhost:3000/reset-password
   http://localhost:3000/**
   ```

### Step 2: メールテンプレート修正
1. [Email Templates](https://supabase.com/dashboard/project/wdttluticnlqzmqmfvgt/auth/templates)を開く
2. **Reset Password**テンプレートを選択
3. **カスタムリンク形式に変更:**

#### オプション1: カスタムリンク（推奨）
```html
<a href="{{ .SiteURL }}/reset-password?token_hash={{ .TokenHash }}&type=recovery">Reset Your Password</a>
```

#### オプション2: デフォルトURL（既存）
```html
<a href="{{ .ConfirmationURL }}">Reset Your Password</a>
```

### Step 3: ResetPasswordPageの修正
カスタムリンク使用時は以下の処理に変更：

```typescript
// URLパラメータから情報を取得
const params = new URLSearchParams(window.location.search);
const tokenHash = params.get('token_hash');
const type = params.get('type');

if (type === 'recovery' && tokenHash) {
  // verifyOtpを使用してセッション設定
  const { data, error } = await supabase.auth.verifyOtp({
    token_hash: tokenHash,
    type: 'recovery'
  });
  
  if (!error && data.session) {
    setIsModalOpen(true);
  }
}
```
