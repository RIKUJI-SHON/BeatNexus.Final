## 4. 方式検討と採用方針
- 方式A（シンプル）: `site_news` に `language` カラムを追加し、言語ごとに別行を作成。
  - 利点: 実装・運用が簡単、既存クエリ/キャッシュを小改修で流用可。

擬似コード:
```ts
const fetchNews = async (lang) =>
  supabase.from('site_news')
    .select('*')
    .eq('is_published', true)
    .eq('language', lang)
    .order('display_order', { ascending: true })
    .order('published_at', { ascending: false })
    .limit(limit ?? 10);
```
