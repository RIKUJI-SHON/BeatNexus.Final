# 広告挿入クイックリファレンス (2025-08-21)
作成者: GitHub Copilot  
参照ドキュメント: `docs/BeatNexus.md`, `docs/広告配信システム_要件定義_2025-08-20.md`, `docs/広告配信フロント実装ガイドライン.md`

> 現在はサスペンドモード (配信/計測無効)。実際の広告取得は行われず `HouseAd` などのフォールバック表示か空表示になります。再開時は `.env` で `VITE_ADS_SUSPENDED=false` を設定し Edge Functions を復活させるだけで本手順はそのまま有効になります。

---
## 1. 何をすれば「広告を入れた」ことになるか
ページ (React コンポーネント) 内の所定位置に `<AdSlot placementKey="..." />` を挿入し、適切な `fallback` とレイアウトクラスを与える。これで将来配信を再開した際に自動的に動的クリエイティブが差し込まれる。

## 2. 既存で使える Placement Keys (active=true)
| Key | 用途 | Variant | 推奨最小高さ目安 |
|-----|------|---------|------------------|
| home.features.mid.inline | Home 特集/機能説明セクション間 | inline | ~160px |
| home.latest.before-list.infeed | Home 最新バトル一覧直前 | infeed | ~220px |
| battles.list.after-3.infeed | Battles 一覧 3件後 | infeed | ~220px |
| battles.list.after-10.infeed | Battles 一覧 10件後 | infeed | ~220px |
| ranking.top.banner | Ranking トップポディウム直下 | banner | 120–160px |
| ranking.list.after-5.infeed | Ranking 一覧 5位後 | infeed | ~220px |

追加候補 (inactive) は `src/config/ads.ts` を参照。

## 3. 基本挿入パターン
### 3.1 セクション間 (Inline / Banner)
```tsx
import { AdSlot } from '@/components/ads/AdSlot';
import { HouseAd } from '@/components/ads/HouseAd';

// 例: HomePage セクション間
<div className="mt-16">
  <AdSlot
    placementKey="home.features.mid.inline"
    variant="inline"
    className="w-full flex justify-center"
    fallback={<HouseAd className="w-full max-w-xl" />}
  />
</div>
```

### 3.2 リスト中断 (InFeed)
リストデータに仮想オブジェクトを挿入するか、インデックスで条件分岐。
```tsx
{items.map((row, idx) => {
  if (idx === 3) return (
    <AdSlot
      key="battles.list.after-3.infeed"
      placementKey="battles.list.after-3.infeed"
      variant="infeed"
      className="my-4"
      fallback={null}
    />
  );
  return <BattleRow key={row.id} data={row}/>;
})}
```

### 3.3 バナー (横長)
```tsx
<AdSlot
  placementKey="ranking.top.banner"
  variant="banner"
  className="w-full flex justify-center"
  fallback={<HouseAd className="w-full max-w-3xl" />}
  render={({ creative, click }) => (
    <div className="bnx-ad-banner w-full max-w-3xl mx-auto p-4 rounded-xl bg-gray-800/60 border border-gray-700/60 flex flex-col md:flex-row gap-4">
      {creative?.file_url && <img src={creative.file_url} alt={creative.headline || 'ad'} className="w-40 h-24 object-cover rounded" />}
      <div className="flex-1 min-w-0">
        <div className="text-xs font-semibold text-cyan-400 mb-1">AD</div>
        {creative?.headline && <h4 className="text-white font-bold text-sm md:text-base line-clamp-2">{creative.headline}</h4>}
        {creative?.body && <p className="text-gray-300 text-xs md:text-sm line-clamp-2 mt-1">{creative.body}</p>}
      </div>
      {creative?.cta_text && creative?.target_url && (
        <button onClick={click} className="mt-2 md:mt-0 px-4 py-2 rounded-lg bg-gradient-to-r from-cyan-500 to-blue-600 text-white text-sm font-semibold">
          {creative.cta_text}
        </button>
      )}
    </div>
  )}
/>
```

## 4. `AdSlot` Props 早見
| Prop | 必須 | 説明 |
|------|------|------|
| placementKey | ✔ | `src/config/ads.ts` に定義されているキー |
| variant | 任意 | 見た目バリアント (現状ロジック未使用 / ドキュメント用途) |
| className | 任意 | 外側ラッパ div のクラス |
| fallback | 任意 | No Fill or サスペンド時に表示する要素 (省略で空) |
| render | 任意 | クリエイティブ受け取り自前レイアウトする関数 (なければデフォルトカード) |
| preloadMargin | 任意 | IntersectionObserver の rootMargin (視界手前でロード) |

---
## 5. サスペンドモード時の挙動
| 状態 | 値 |
|------|----|
| `useAdServe` fetch | 実行されない |
| `creative` | `null` |
| `noFill` | `true` (有効キー) / エラー (無効キー) |
| Impression / Click Hook | token 不在で送信スキップ |

フォールバックを指定していれば表示される。無指定なら単純な空領域 (collapse) になる。

---
## 6. 新しい広告枠を追加する手順
1. `src/config/ads.ts` の `AD_PLACEMENTS` にキーを追加 (`active:false` で開始)。
2. 要件定義 27.x セクションへ行追加 (配置説明 / variant / 目的)。
3. 対象ページへ `<AdSlot placementKey="..." />` を挿入。
4. レイアウト安定のため必要ならプレースホルダ高さ (min-h-[...] 等) をクラス付与。
5. PR レビュー時: 命名規約・高さ崩れ・fallback 方針を確認。
6. 後日再開時 `active:true` にし Edge Function 稼働で自動化。

---
## 7. よくあるミスと対策
| ミス | 症状 | 対策 |
|------|------|------|
| 未登録の placementKey | `INVALID_PLACEMENT_KEY` エラー div | `ads.ts` にキーを追加 or typo 修正 |
| Fallback 未指定 infeed | 空白行が詰まる/気付きにくい | 意図的ならコメント残す / HouseAd を渡す |
| CLS ジャンプ | スクロール中に高さ変化 | 最低高さクラスを先に付与 |
| render 使用時 click 忘れ | CTA クリック計測 (再開後) されない | `click()` を必ずボタン onClick に渡す |
