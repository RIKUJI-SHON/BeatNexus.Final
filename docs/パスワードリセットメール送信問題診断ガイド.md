## 🚨 現在の症状
- パスワードリセット要求は送信されるが、メールが届かない
- エラーメッセージは表示されない

## 🔍 確認すべき設定項目（優先順）

### 1. 最重要：Authentication設定の確認

#### 1.1 Site URL設定
**場所**: Supabaseダッシュボード > Authentication > Settings > Site URL

**現在設定すべき値**:
```
開発環境: http://localhost:3000
本番環境: https://beatnexus.com
```

**確認方法**:
1. https://supabase.com/dashboard にログイン
2. プロジェクト「BeatNexus.DEV」を選択
3. 左サイドバー「Authentication」→「Settings」
4. 「Site URL」欄を確認

#### 1.2 Redirect URLs設定
**場所**: Authentication > Settings > Redirect URLs

**追加すべき値**:
```
http://localhost:3000/reset-password
https://beatnexus.com/reset-password
```

**設定手順**:
1. 「Add URL」ボタンをクリック
2. 上記URLを追加
3. 「Save」をクリック

### 2. Email Templates設定

#### 2.1 Reset Password Template
**場所**: Authentication > Email Templates > Reset Password

**確認項目**:
- [ ] テンプレートが有効になっている
- [ ] Subject欄が設定されている
- [ ] Body（HTML）が設定されている
- [ ] `{{ .ConfirmationURL }}`変数が含まれている

**デフォルトテンプレート**:
```html
<h2>Reset Your Password</h2>
<p>Follow this link to reset the password for your user:</p>
<p><a href="{{ .ConfirmationURL }}">Reset Password</a></p>
```

### 3. SMTP設定確認

#### 3.1 SMTP Provider設定
**場所**: Authentication > Settings > SMTP Settings

**開発環境での選択肢**:
1. **Enable custom SMTP**: OFF（Supabaseデフォルト使用）
2. **Enable custom SMTP**: ON（独自SMTP使用）

**推奨設定（開発環境）**:
- まずはSupabaseデフォルトSMTPを使用（Enable custom SMTP: OFF）
- 問題が解決しない場合のみカスタムSMTP設定

#### 3.2 From Email設定
**場所**: Authentication > Settings > SMTP Settings

**設定値**:
```
From email: noreply@wdttluticnlqzmqmfvgt.supabase.co
From name: BeatNexus
```

### 4. レート制限確認

#### 4.1 認証レート制限
**場所**: Authentication > Settings > Rate Limits

**確認項目**:
- Password reset: 現在の制限値を確認
- 制限に達していないか確認

**デフォルト値**:
- Password reset: 5 requests per hour per IP
