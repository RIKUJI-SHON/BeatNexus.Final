# ポート番号修正ログ - localhost:3000に統一

## 📅 修正日
2025年8月5日

## 🚨 発見された問題
パスワードリセット機能でメールが届かない原因として、**ポート番号の設定ミス**が判明しました。

### 問題の詳細
- **誤った設定**: `localhost:5173` を使用
- **正しい設定**: `localhost:3000` を使用
- **根拠**: `package.json`で `"dev": "vite --port 3000"` と明確に定義

## ✅ Supabaseダッシュボードで設定すべき正しい値

### Authentication > Settings
- **Site URL**: `http://localhost:3000`
- **Redirect URLs**: `http://localhost:3000/reset-password`

### これが解決すべき根本原因
パスワードリセットメールが届かない問題は、Supabaseダッシュボードで設定されているSite URLとRedirect URLsが実際の開発サーバーのポート（3000）と一致していないことが原因の可能性が非常に高いです。
