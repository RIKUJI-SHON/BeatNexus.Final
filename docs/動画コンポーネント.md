# iPhone動画再生問題 解決計画書

## 作成日
2025年1月8日

## 問題の概要
BattleView.tsxにおいて、iPhoneデバイスでPlayer Bの動画が再生できない問題が発生しています。

### 症状
- Player A（1つ目）の動画：正常に読み込み・再生可能
- Player B（2つ目）の動画：読み込み失敗エラー
- 影響範囲：すべてのiPhoneデバイス、すべてのブラウザ
- PC/Android：両方の動画が正常に動作

## 根本原因分析

### 1. iOS Safariの技術的制限
- **メモリ制限**: iOSは複数の動画を同時にメモリに保持することを制限
- **preload制限**: 2つ目以降の動画でpreload="metadata"が正しく動作しない
- **リソース管理**: iOS Safariが2つ目の動画のリソース割り当てを制限

### 2. 現在の実装の問題点
- `playsinline`属性の欠如によるインライン再生の保証なし
- `src`属性と`<source>`タグの重複指定
- iOS特有の属性（`webkit-playsinline`）の未設定
- 両動画の同時preloadによるリソース競合

```typescript
// utils/videoSupport.ts に追加
export const isIOSSafari = (): boolean => {
  const ua = window.navigator.userAgent;
  const iOS = !!ua.match(/iPad/i) || !!ua.match(/iPhone/i);
  const webkit = !!ua.match(/WebKit/i);
  const iOSSafari = iOS && webkit && !ua.match(/CriOS/i);
  return iOSSafari;
};

export const getIOSVideoProps = () => {
  if (!isIOSSafari()) return {};
  
  return {
    playsInline: true,
    'webkit-playsinline': 'true',
    preload: 'none' as const,
  };
};
```

### Phase 3: 遅延読み込み実装
**実装期間**: 1週間以内
**リスクレベル**: 中

#### 3.1 Intersection Observerの実装

```typescript
// hooks/useIntersectionObserver.ts
export const useIntersectionObserver = (
  ref: RefObject<Element>,
  options?: IntersectionObserverInit
): boolean => {
  const [isIntersecting, setIsIntersecting] = useState(false);

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => setIsIntersecting(entry.isIntersecting),
      options
    );

    if (ref.current) {
      observer.observe(ref.current);
    }

    return () => {
      if (ref.current) {
        observer.unobserve(ref.current);
      }
    };
  }, [ref, options]);

  return isIntersecting;
};
```

#### 3.2 BattleViewでの遅延読み込み

```typescript
const [playerAVideoLoaded, setPlayerAVideoLoaded] = useState(false);

  if (playerAInView && !playerAVideoLoaded) {

useEffect(() => {
  if (playerBInView && !playerBVideoLoaded) {
```

#### 4.2 動画プリロード戦略の改善
```typescript
// 動画プリロード管理クラス
class VideoPreloadManager {
  private static instance: VideoPreloadManager;
  private loadingQueue: string[] = [];
  private maxConcurrent = isIOSSafari() ? 1 : 2;
  
  public async preloadVideo(url: string): Promise<void> {
    // キューに追加して順次読み込み
    this.loadingQueue.push(url);
    await this.processQueue();
  }
  
  private async processQueue(): Promise<void> {
    // 同時読み込み数を制限
    while (this.loadingQueue.length > 0) {
      const batch = this.loadingQueue.splice(0, this.maxConcurrent);
      await Promise.all(batch.map(url => this.loadVideo(url)));
    }
  }
}
```
