作成者: GitHub Copilot  
対象リポジトリ: BeatNexus  
参照基礎ドキュメント: `docs/BeatNexus.md`

## 0. 背景 / Purpose
BeatNexus プラットフォーム内で企業・団体向けに広告掲載枠を提供し、収益化（ターゲット広告モデル）を実現する。初期フェーズでは限定的な枠と単純ターゲティングで MVP を構築し、計測基盤・運用フローを確立する。

## 1. スコープ
- アプリ内広告配信（インフィード / ニュースカルーセル枠）
- 広告主/キャンペーン/クリエイティブ/フライト管理（運営向け管理 UI）
- 基本ターゲティング（国 / 言語 / デバイス）
- インプレッション / クリック計測 (IntersectionObserver + CTA ボタン押下)
- 配信キャップ (ユーザー単位日次上限) の定義（初期はロジック最小実装）
- KPI 可視化（最小: インプレッション数 / クリック数 / CTR）

## 2. 非スコープ (初期リリース)
- 自動課金 / 請求書発行
- 高度ターゲティング（行動履歴、興味属性、リターゲティング）
- リアルタイム入札 (RTB)
- 広告主向けセルフサーブ UI
- ブランドセーフティ自動審査 / ML フィルタ
- 広告不正検知 (Fraud detection)

## 3. 用語定義
- 広告主 (Advertiser): 企業・団体
- キャンペーン (Campaign): 目的単位の広告活動
- クリエイティブ (Creative): 表示素材 (画像 / 動画 / 記事風)
- フライト (Flight): 特定配置 + ターゲティング + 期間設定単位
- 配置 (Placement): アプリ内の固定広告枠識別キー
- イベント (Ad Event): impression / click の測定ログ

## 4. ユーザーロール
| ロール | 説明 | 権限概要 |
|--------|------|----------|
| internal_admin | 運営チーム | 全権限 (RLS BYPASS) |
| ad_ops | 広告運用担当 | 広告関連 CRUD + レポート閲覧 |
| viewer | 分析/経営 | 閲覧のみ |
| end_user | 一般ユーザー | 広告閲覧のみ |

## 5. ユースケース (代表)
1. 運営が広告主情報を登録する
2. キャンペーンを作成し、期間・目的を設定
3. クリエイティブ素材をアップロードし CTA / テキストを設定
4. 配置一覧から利用可能な枠を選びフライトを定義（ターゲティング + imp_goal + daily_cap）
5. 公開 (status=active) 後、ユーザーのフィードで表示ロジックがマッチした場合に挿入
6. 表示条件を満たした際に impression 記録、CTA 押下時に click 記録
7. 運営 UI で集計値を閲覧し最適化・停止

## 6. UI / 表示要件
### バッジ
- ラベル: 「広告 / AD」 (i18n: ja=広告, en=AD) 両方並列表記を初期仕様とする
- UI キット化: `AdBadge` コンポーネント（props: size, theme）
- コントラスト比: WCAG AA 準拠 (背景: ダークテーマ上で 4.5:1 以上)

### 枠テンプレート
1. インフィードカード: 既存バトルカード風レイアウトを踏襲（高さ統一, サムネ + テキスト + CTA ボタン）
2. ニュースカルーセル枠: 横スクロール記事風カード。1枚あたり: 画像 / 見出し / バッジ / CTA

### 計測仕様
- インプレッション: IntersectionObserver threshold=0.5 を連続 1000ms 以上可視で 1 カウント（再入可: 30秒内再表示は二重カウント防止）
- クリック: CTA ボタン（要 data-ad-* 属性）押下時に記録
- デバウンス: 同一 creative + placement + user で 5 秒以内重複クリック無効

## 9. データモデル (初期スキーマ案)
```sql
-- 1. advertisers
create table if not exists advertisers (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  contact_info jsonb,
  billing_info jsonb,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

-- 2. ad_campaigns
create table if not exists ad_campaigns (
  id uuid primary key default gen_random_uuid(),
  advertiser_id uuid references advertisers(id) on delete cascade,
  name text not null,
  objective text check (objective in ('awareness','application','traffic') ),
  start_date date not null,
  end_date date not null,
  status text not null check (status in ('draft','active','paused','ended')),
  created_at timestamptz default now(),
  updated_at timestamptz default now(),
  constraint campaign_date_range check (end_date >= start_date)
);
create index on ad_campaigns (advertiser_id);
create index on ad_campaigns (status);

-- 3. ad_creatives
create table if not exists ad_creatives (
  id uuid primary key default gen_random_uuid(),
  campaign_id uuid references ad_campaigns(id) on delete cascade,
  type text not null check (type in ('image','video','article')),
  file_url text,
  headline text,
  body text,
  cta_text text,
  target_url text,
  dimensions text,
  metadata jsonb,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
create index on ad_creatives (campaign_id);

-- 4. ad_placements
create table if not exists ad_placements (
  id uuid primary key default gen_random_uuid(),
  key text unique not null,
  description text,
  size text,
  is_active boolean default true,
  created_at timestamptz default now()
);
create index on ad_placements (is_active);

-- 5. ad_flights
create table if not exists ad_flights (
  id uuid primary key default gen_random_uuid(),
  campaign_id uuid references ad_campaigns(id) on delete cascade,
  placement_id uuid references ad_placements(id) on delete cascade,
  targeting_json jsonb,
  daily_cap int,
  imp_goal int,
  weight int default 1,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
create index on ad_flights (campaign_id, placement_id);
create index on ad_flights using gin (targeting_json);

-- 6. ad_events (大規模化を想定し将来パーティション)
create table if not exists ad_events (
  id bigserial primary key,
  creative_id uuid references ad_creatives(id) on delete cascade,
  placement_id uuid references ad_placements(id) on delete restrict,
  flight_id uuid references ad_flights(id) on delete set null,
  type text not null check (type in ('impression','click')),
  user_id uuid,
  anon_session_id text,
  occurred_at timestamptz not null default now(),
  client_meta jsonb
);
create index on ad_events (creative_id, type, occurred_at);
create index on ad_events (placement_id, occurred_at);
create index on ad_events (user_id, occurred_at);
```

## 10. RLS / アクセス制御方針
- `ad_events`: 直接クライアント挿入禁止（Edge Function 経由）
- `advertisers`, `ad_campaigns`, `ad_creatives`, `ad_flights`, `ad_placements`: internal_admin / ad_ops のみ書込み
- viewer: 読取のみ
- end_user: 読取 (配信判定用サニタイズビュー) のみ

## 11. 配信ロジック (サーバ / Edge Function)
1. 入力: placement_key, user_context(country, lang, device, user_id(optional))
2. 候補抽出: active キャンペーン + 日付範囲内 + placement_id 一致 + placement.is_active
3. ターゲティングフィルタ: targeting_json 内条件 (例: countries[], languages[], devices[])
4. デイリーキャップ判定: 当該 user_id or anon_session_id の本日 impression 数 >= daily_cap のフライト除外
5. imp_goal 判定: 当該フライトの累積 impression >= imp_goal なら除外
6. 重み付け選択: 重み (weight) に基づきランダムサンプリング
7. 戻り値: creative 情報 + tracking token (署名付き JWS) + TTL

### トークン構造
```json
{ "creative_id": "...", "flight_id": "...", "placement_id": "...", "exp": 1699999999 }
```
- Impression 記録時にトークン再検証 (改ざん防止)

## 12. 計測フロー
- フロント: IntersectionObserver → visibility >=50% 連続 1000ms → `/ad/impression` 送信 (token, client_meta)
- CTA クリック: `/ad/click` 送信 (token, client_meta)
- サーバ: token 検証 → 重複判定 (redis or 最小: 最近 5 秒 within same key) → `ad_events` 挿入

## 13. 集計 / レポート
最小: 日次集計マテリアライズドビュー (将来バッチ)
```sql
create materialized view if not exists mv_ad_stats_daily as
select 
  date_trunc('day', occurred_at) as day,
  creative_id,
  placement_id,
  flight_id,
  count(*) filter (where type='impression') as impressions,
  count(*) filter (where type='click') as clicks
from ad_events
where occurred_at >= (now() - interval '30 days')
group by 1,2,3,4;
```
リフレッシュ頻度: 5-15 分間隔 (初期はオンデマンド管理 UI トリガ)

## 17. セキュリティ
- 署名: Edge Function 秘密鍵で JWS 発行
- RLS: role claim により SELECT 制御
- XSS: クリエイティブ body はサニタイズ (許可タグ whitelist)
- リンク: target_url rel="noopener noreferrer"

## 18. パフォーマンス戦略
- 配信候補: キャッシュ (placement+country+lang キー) 30-60 秒
- イベント挿入: バルク不可（即時書込み）だが将来キュー化検討

### 27.4 フロント実装インターフェース案
```
<AdSlot
  placementKey="battles.list.after-3.infeed"
  variant="infeed"
  className="my-6"
  render={(creative) => <InFeedAdCard creative={creative} />}
  renderFallback={() => null}
/>
```
#### AdSlot props 契約（想定）
- placementKey: string (必須)
- variant: 'infeed' | 'banner' | 'inline' | 'sidebar' | 'carousel'
- render(creative): ReactNode （クリエイティブ描画）
- renderFallback(): ReactNode （No Fill 時）
- preloadMargin: string (例 '300px') → IntersectionObserver rootMargin

#### ライフサイクル
1. プレースホルダ描画（レイアウト高さ確保）
2. ビューポート接近 (preloadMargin 内) → `/ad/serve?placement=...` fetch
3. クリエイティブロード後 DOM 差し替え
4. 50% 可視化連続 1000ms → impression POST
5. CTA `data-ad-cta` クリック → click POST (5s デバウンス)

### 27.5 InFeed 挿入ヘルパー
純関数 `injectAdSlots<T>(items: T[], rules: { index: number; placementKey: string }[])` で指定 index 後に仮想 AdSlot ノードを挿入。
例: `[{index:3, placementKey:'battles.list.after-3.infeed'},{index:10, ...}]`
No Fill でも元配列 index の整合性維持（AdSlot 自身が collapse するため再計算不要）。

### 27.6 NewsCarousel への挿入
- カルーセルアイテム取得後 `if (items.length >= 5)` → index 4 の後に AdSlot
- placementKey: `battles.carousel.after-4.card`
- ループ / 無限スクロールの場合は 1 セッション 1 回のみ表示（state で制御）

### 27.7 No Fill ポリシー
| シナリオ | 挙動 |
|----------|------|
| InFeed | 完全非表示 (margin collapse) - レイアウトジャンプ防止のため最初から最小高さ 0 placeholder |
| Banner / Inline | Fallback を House Ad（自社誘導）で埋める（CTR ベースで AB 可） |
| Sidebar | Fallback = ランキング Tips / コミュニティ参加誘導 |
| Carousel | Ad カード欠落時は単に通常記事列挙続行 |

### 27.8 計測実装要点
- IntersectionObserver: threshold=[0.5] で開始タイムスタンプ記録 → 1000ms 継続で確定
- 再表示 30 秒以内同一 (creative_id + placement_id + session_key) 無視
- クリック: `onClick` で token + meta (viewport, lang, device) 送信
- デバウンス key: `${creative_id}:${placement_id}:${user_or_anon}:${event_type}`
